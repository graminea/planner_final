# Figueirense FC Assets

This folder contains Figueirense Futebol Clube branding assets for the "Figueira Porra" theme.

## Required Images

Place the following images in this folder:

### 1. **logo.svg** or **logo.png**
- Figueirense FC official logo
- Recommended size: 512x512px
- Used in: App header/navigation when Figueira theme is active

### 2. **mascot.svg** or **mascot.png**  
- Figueirense mascot (Furacão)
- Recommended size: 512x512px
- Can be used in: Empty states, loading screens, dashboard decorations

### 3. **icon.svg** or **icon.png**
- Simplified icon/badge version
- Recommended size: 128x128px
- Used in: Small UI elements, favicon alternative
